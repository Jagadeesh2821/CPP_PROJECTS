# CPP Projects

CPP Projects — modular Smart Vehicle Control System and an event-driven Automotive Dashboard simulator modeling vehicle behavior and real-time monitoring.

## Projects

- SMART VEHICLE CONTROL SYSTEM (C++) — Modular simulator for engine operations, acceleration, braking, refuelling, and real-time speed/fuel alerts.
- EVENT-DRIVEN AUTOMOTIVE DASHBOARD SIMULATOR (C++) — Real-time dashboard simulator processing speed, RPM, and fuel signals with observer/event-driven updates.

## Build

Compile the example with:

```bash
g++ -Wall -Wextra -g Vehicle.cpp AlertSystem.cpp Main.cpp -o output/Hello.exe
```
